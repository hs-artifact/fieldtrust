# Roadmap

FieldTrust grows in public releases. Each release deepens one part of the product.

| Release | Focus | Adds |
|---|---|---|
| **v1.0** (current showcase) | All five disciplines at demo depth | Two domain packs, medallion pipeline, rule engine, governance catalogue, ops, stage gates, adoption |
| v1.1 | Data engineering depth | PostgreSQL target, incremental loads, late-arriving data handling, pipeline unit tests |
| v1.2 | Data quality depth | Statistical checks (flatline, drift, outliers), rule versioning, steward work queue |
| v1.3 | Geospatial & streaming | PostGIS haul-road and well-pad geofences, MQTT telemetry simulator, near-real-time freshness |
| v1.4 | API & integration | REST API over gold, OpenAPI spec, a sample integration with a reporting tool |
| v1.5 | Digital operations depth | Alert rules as code, on-call rota, post-incident review template, SLO burn-down |
| v2.0 | Decision support | Shift handover brief generated from trust-qualified KPIs; data-driven change plan per group |

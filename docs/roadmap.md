# Roadmap

FieldTrust grows in public releases. Each release deepens one part of the product.

| Release | Focus | Adds |
|---|---|---|
| **v1.1.4** (current) | Hiring pathways | "Where to look" by role on the overview and in the README, contact details, v1.2 refocused on hydrocarbon accounting |
| v1.1.3 | Proof & polish | Test suite and CI gate, value at stake on live hand-offs, motion control, README visuals, link preview, steel day mode |
| v1.1.2 | Value chain, live | LNG liquefaction at the terminal, live hand-off markers from the reconciliation rules, packet rate driven by data frequency, phone zoom |
| v1.1.1 | Value chain | Animated reservoir-to-vessel and pit-to-shipment scenes, each stage mapped to data type, format, frequency, consumers, function and hand-off checks; guided tour and data map |
| v1.1 | Framework & interaction | Field-to-Decision framework, stakeholder layers, goal tree, maturity, playbook of normal and edge cases, 90-day replay, what-if simulator, live pipeline animation |
| v1.0 | All five disciplines at demo depth | Two domain packs, medallion pipeline, rule engine, governance catalogue, ops, stage gates, adoption |
| v1.2 | Hydrocarbon accounting | PostgreSQL target with a PPDM-style model, daily back allocation with field factor, period close and restatement, equity and entitlement split, well KPIs, PRODML export, incremental loads |
| v1.3 | Data quality depth | Statistical checks (flatline, drift, outliers), rule versioning, steward work queue |
| v1.4 | Geospatial & streaming | PostGIS haul-road and well-pad geofences, MQTT telemetry simulator, near-real-time freshness |
| v1.5 | API & integration | REST API over gold, OpenAPI spec, a sample integration with a reporting tool |
| v1.6 | Digital operations depth | Alert rules as code, on-call rota, post-incident review template, SLO burn-down |
| v2.0 | Decision support | Shift handover brief generated from trust-qualified KPIs; data-driven change plan per group |
